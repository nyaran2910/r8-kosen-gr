## 研究概要

従来の学習方法では、学習に使う資料の選定、問題と解答の参照位置の切り替え、参考書間の往復など、数多くのオーバーヘッドが生じる。
本研究では、これらの非本質的な操作を生成AIとソフトウェアを用いてよって減らし、効率的な学習を実現することを目的とする。

具体的には、問題生成、解答生成、解説資料作成を一体化し、知識を要素単位に分解する。その上で、大学や資格の要件に応じて必要な要素を選び、コスト設定などを用いて学習内容を最適化する。
主要なソフトウェア成果は、知識要素、問題、解答、解説、引用元、大学傾向、学習履歴、復習予定を扱うREST APIとする。FastAPI、PostgreSQL、pgvectorで最小プロトタイプを構築し、実験に必要な最小フロントエンドを接続する。

データは、東北大学令和7・8年度の数学全範囲を使う傾向・問題生成用データセットと、同校3年生の微積分学習比較に使うデータセットを共通形式で管理する。学習比較では、事前テスト、60分学習、事後テストを行い、アプリ条件と参考書3冊の条件で到達度と学習体験を比較する。

市販参考書は一般的な知識、数式、技能、関係を人手で確認するための参考資料として使う。本文、固有の問題・解説・図をデータセットへ転記せず、研究者が独自に記述した知識要素と作問条件から新しい問題、解答、解説を生成する。

# 動作確認用データ

`demo.sql` は自作の数学問題3問と、それに対応する教科・試験・ジャンル・形式・知識要素5件を登録する。
原本の問題やユーザー情報・学習履歴は含まない。試験名は画面確認用で、実際の出題傾向を保証するものではない。知識のコストは未決定なので `NULL`。

DBを起動し、マイグレーションを適用してから、リポジトリのルートで実行する。

```sh
just seed-db
```

固定IDを使い、同じIDが存在すればスキップする。繰り返し実行しても重複せず、既存データも上書きしない。SQLファイルを編集して再実行しても、既存レコードへの変更は反映されない。
全体を一つのトランザクションで実行し、エラーがあればロールバックする。

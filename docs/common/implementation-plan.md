# 実装計画

更新日：2026-10-13。ユーザーが実装し、アシスタントは手順案内と読み取り確認を担当。

## 現在地

ローカルのWeb・API・DB、API中継とDB接続確認、初版の19テーブルとマイグレーションが作成・適用済み。Auth.jsのWeb認証コードは作成済みだが、Googleログインの成功は未確認。学習API・データ登録・評価更新はこれから。

2026-10-13、認証をFastAPIへ集約する方針に変更した。次はAPI側の認証ライブラリ・セッション方式を決め、Google認証→内部ユーザー→本人取得を動かしてからNext.js側を置き換える。

アシスタントはコード・依存・設定・DBを直接変更せず、ユーザーへコマンドとコードを案内する。標準のinit/add/autogenerateを使い、ライブラリへ委譲できる部分は任せる。新しい操作・概念は説明し、既知のモデル定義や変更適用はまとめて進める。設計文書の整理は継続する。

## 実装順の案

| 段階 | 内容 |
| --- | --- |
| 1 | Web・API・DBのローカル起動基盤 |
| 2 | DBとGoogle認証、ユーザー分離、退会後の認証拒否 |
| 3 | レビュー済みデータ登録と本文・画像・知識リンクの閲覧 |
| 4 | 演習・評価・理解度更新・履歴・手動変更、中断再開と再送 |
| 5 | 復習と弱点による出題、バックアップ・退会台帳・復元確認 |

設計確認のためだけに新しい機能を追加し続けない。依存の版・実際の保存先・正式な型や制約などは該当段階で具体化し、仕様変更が必要なら確認する。各段階の結果をまとめてレビューする。詳細な完了基準は [初版の完成条件](local-operation-review.md)。

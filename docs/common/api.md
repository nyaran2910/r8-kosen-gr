# 認証設定とAPI契約

認証設定・APIの基本契約・再送と競合の扱いはユーザー確認済み。コード・依存・環境構築は行わない。

## 認証の現行方針

2026-10-13、認証をFastAPI側へ集約する方針に変更した。APIがGoogleログイン・ユーザー登録・セッション・本人確認・退会を担当し、Next.jsは表示と中継を行う。

最後の利用から24時間でログイン期限切れにする要件は維持する。旧案のNext.js発行API用JWT・60秒期限・RS256鍵分担は採用しない。Cookieまたはセッションの具体的な方式、認証用のURL、CSRF対策をAPI側のライブラリと合わせて選定する。

Googleログイン開始・callback・ログアウト・本人取得の認証APIを追加する。URLとGoogle側のredirect URIは方式を確認してから具体化し、現在のAuth.js用callbackと混同しない。

## APIの担当

ブラウザーはNext.jsの同一オリジンのAPIへアクセスし、Next.jsがFastAPIへ中継する。下記はFastAPI側の `/api/v1` 配下の案。

| 操作 | API案 |
| --- | --- |
| 本人・試験一覧 | `GET /me`、`GET /exams` |
| 退会 | `DELETE /me`（学習データは保持） |
| 知識・形式一覧と詳細 | `GET /knowledge`、`GET /knowledge/{id}`、`GET /exams/{id}/formats` |
| 未確定演習の確認 | `GET /attempts/active` |
| 次の問題を開始 | `POST /attempts/next` |
| 履歴から解き直し | `POST /attempts` |
| 演習の取得・再開 | `GET /attempts/{id}` |
| 表示開始の通知 | `POST /attempts/{id}/start` |
| 解答の表示 | `POST /attempts/{id}/reveal` |
| 評価確定・未確定終了 | `POST /attempts/{id}/feedback`、`POST /attempts/{id}/close` |
| 理解度の手動設定 | `PUT /knowledge/{id}/understanding`、`PUT /exams/{id}/formats/{format_id}/understanding` |
| 確定した演習の履歴 | `GET /attempts` |

ユーザーIDは入力させず、認証情報から特定する。解答表示前の演習取得には解答・解説を含めない。確定済み演習の取得では当時の評価・変化を返す。一覧は最大50件ずつ取得する案。

## 評価保存・再送

問題評価と全使用知識の二択評価を一回の要求で送る。サーバーが理解度を計算し、履歴・現在理解度・復習予定をまとめて保存する。

- 同じ演習に同じ評価を再送したら、元の保存結果を返す。二重更新しない。
- 確定後に違う評価を送ったら競合エラーにする。変更は理解度の手動設定で行う。
- 演習開始にも操作を識別するIDを付け、通信失敗で同じ操作を再送しても演習を増やさない。
- 手動変更は表示時の更新日時も送る。別タブ等で値が変わっていたら再取得を案内する。

## エラーと画面の動作

| 状況 | 動作 |
| --- | --- |
| 未ログイン・期限切れ | 再ログインを案内。演習を勝手に新規作成しない |
| 他人の演習・存在しない対象 | 見つからない旨を表示 |
| 評価の不足・不正な値 | 該当項目を表示し、入力を保持 |
| 確定・終了済み、同時操作の競合 | 最新状態を取得し直す |
| 通信失敗 | 入力を保持して再試行できる。保存成功と表示しない |
| 出題候補なし | 正常な結果として候補なし・次回復習日時を表示 |

詳細な状態遷移・JSONの項目名は [AI用のAPI契約](../ai/api.md) に保存する。

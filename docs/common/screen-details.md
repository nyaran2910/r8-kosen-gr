# 初版の画面操作の詳細案

試験ホーム・知識形式一覧・履歴設定の3項目はユーザー確認済み。実装しない。

## 1. 試験選択とホーム

試験一覧では試験区分・教科・名称検索で絞り込む案。各項目に試験名・区分・教科を表示する。最近使った試験を同じブラウザーで覚え、ログイン後にそのホームへ戻れるようにする。試験を切り替える入口は常に残す。

ホームには「学習を始める」、復習待ち件数、未確定演習があれば「続きから」、知識・形式・履歴への入口を置く。別試験の未確定演習でも、その試験名と再開入口を表示する。試験を閲覧するだけでは演習を終了しない。

登録問題がない試験も一覧に表示し、ホームでは学習開始できない旨を説明する。候補がない場合と未登録は区別する。

## 2. 知識・形式の一覧と理解度変更

知識一覧は教科・ジャンル・名称検索・理解度で絞り込む案。未評価を1〜5とは別の絞り込み条件にする。試験ホームから開いた場合は、その試験の対象ジャンルで絞るが、試験の出題範囲を保証する一覧とは表示しない。

形式一覧は選択した試験の形式だけを表示し、構成・回答形式・名称・自分の理解度を確認できる。

理解度は詳細ページや演習中の知識パネルで1〜5を選び、「保存」で変更する。一覧の操作だけでは値を変更しない。未評価は初回設定できるが、初版に「未評価へ戻す」操作は設けない。保存すると現在値に反映し、演習中に変更した場合も評価確定は最新値を基準に増減する。

## 3. 履歴とアカウント設定

履歴は確定した演習を新しい順に表示し、試験・日付範囲・4段階評価で絞り込む案。問題に表示タイトルのカラムを増やさず、本文の冒頭抜粋を一覧の見出しにする。

履歴詳細で問題・解答・解説・知識評価・知識と形式の理解度変化・回答時間・当時の復習予定を確認できる。閲覧だけでは更新しない。出題可能な問題には「もう一度解く」を表示し、廃止問題は閲覧のみとする。

設定にはログアウトと「Google連携を解除して退会」を置く。「学習データは保持され、再登録しても引き継がれない」と実行前に表示する。学習データ削除・リセットのボタンは設けない。Google側の許可取消しは別操作と説明する。

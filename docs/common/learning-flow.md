# 画面と学習フローの案

画面構成・学習フロー・中断と再開の方針はユーザー確認済み。実装は行わない。既に確認済みの評価ルールを前提とする。

## 画面構成

| 画面 | 主な操作 |
| --- | --- |
| ログイン | Googleでログイン |
| 試験選択 | 試験区分・教科で絞り込み、対象試験を選ぶ |
| 試験のホーム | 学習開始、中断した演習の再開、知識・形式・履歴の確認 |
| 演習 | 問題、解答・解説、知識評価、問題評価を同じ画面で扱う |
| 知識一覧・詳細 | 本文・関連知識を閲覧し、自分の理解度を変更 |
| 形式一覧・詳細 | 選択した試験の形式・自分の理解度を確認・変更 |
| 学習履歴 | 確定した演習の問題・評価・時間・当時の理解度変化を確認 |

## 一回の学習

1. 試験を選び、「学習を始める」を押す。
2. 対象の大問を一つ表示し、演習を開始する。
3. 「答えを見る」で解答・解説を表示する。初回の操作で回答時間の計測を終える。
4. 解説から知識の詳細へ移動し、同じ演習へ戻れる。
5. 全使用知識の「わかった／わからない」と、問題全体の4段階評価を入力する。
6. 「評価を保存」で確定する。理解度更新と次回復習予定を保存し、結果を表示する。
7. 「次の問題」または「学習を終える」を選ぶ。確定しただけで次の演習を自動開始しない。

初版は紙などで解き、アプリでは自己評価を入力する案。解答入力欄・自動採点は設けない。

## 中断・再開

- 中断した演習は同じIDで再開し、開始時刻・解答表示状態を維持する。
- 初版はユーザーごとに未確定の演習を一つにする案。別の問題・試験を始める場合は、再開するか中断演習を終了するか選ぶ。
- 中断演習の終了は「諦めた」の評価とは別。理解度・復習予定を更新しない。終了した未確定演習を再開できるかは、初版では不可の案。
- 入力途中の評価は同じブラウザー・同じタブの再読み込みで復元する案。別端末への同期は初版では行わない。
- ログアウト時に入力途中の評価を消す。演習自体はDBに残り、再ログイン後は評価を入れ直して再開できる。
- 「評価を保存」が失敗した場合は入力を保持して再送できる。保存の確認前に次の問題へ進まない。

中断中の時間も回答時間に含むことは確認済み。確定済みの評価は履歴から変更せず、理解度の手動変更は確認画面から行う。

## DBへの反映と次の設計

中断演習の終了は `attempts.closed_at` で記録する。未確定かつ未終了の演習だけを再開できる。確定・終了済みの演習は別IDで解き直す。

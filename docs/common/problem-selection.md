# 初版の出題ルール案

初版の出題ルールはユーザー確認済み。実装は行わない。復習予定の計算とは別の処理とする。

## 自動出題の候補

選択した試験のレビュー済み・出題可能な問題だけを対象にする。

- まだ評価を確定していない問題。
- 評価確定済みで、次回復習日時を迎えた問題。

復習日時に達していない評価済み問題は自動出題しない。再開可能な演習があれば、新しい問題を作らず再開を案内する。

## 優先順位

1. 復習日時を迎えた問題を優先する。復習日時が古い順。
2. 残りは、未評価の知識を含む問題を優先する。
3. その中では、評価済みの知識の最低理解度が低い問題を優先する。
4. 同条件なら、その試験の形式理解度が低い問題を優先する。未評価の形式を先にする。
5. 最後まで同条件なら問題IDの順で決める。

例えば、復習待ちが一問あり、新しい問題が十問あれば、まず復習待ちを出す。復習待ちがなく、同じ未評価条件の問題に理解度1と4の知識があれば、1を含む方を先にする。

未評価は理解度3と区別する。複数知識の理解度は、初版では平均ではなく最低値を見る。

## 候補がない場合

自動生成は行わず、「今の出題候補はありません」と表示する。将来の復習予定があれば最も近い日時も表示する。登録問題がゼロの場合は「この試験の問題はまだありません」と区別する。

知識・形式の確認や別試験への移動はできる。履歴からの任意の解き直しは次項のルールで可能。

## 履歴から解き直す

復習日時前でも、出題可能な問題は履歴から手動で解き直せる案。新しい演習IDを作る。評価を確定すれば、通常と同じく理解度を更新し、次回復習日時をその確定日時+72時間へ更新する。

単に履歴の解答・解説を見るだけでは、新しい演習や評価・復習更新は発生しない。任意の解き直しは、自動出題のパラメータ指定機能とは別の操作とする。

中断演習を終了した直後は、自動出題で同じ問題が続かないよう、その問題を次の一回の選択だけ除く案。他の候補がなければ「別の候補はありません」と表示し、同じ問題の解き直しは本人が選べる。

## 後で調整すること

復習を優先するため、復習待ちが多い日は新規問題が後回しになる。初版で挙動を確認し、必要なら復習と新規の比率を追加する。問題の難易度・コストによる優先順位は尺度が決まってから検討する。

# 初版の技術設定案

描画・画像制限・通信・鍵配置の設定はユーザー確認済み。実装・インストール・秘密鍵の生成は行わない。

| 項目 | 初版案 |
| --- | --- |
| Markdown表示 | react-markdown＋remark-gfm |
| 数式表示 | remark-math＋rehype-katex＋KaTeX |
| 画像 | PNG・JPEG・WebP。1枚5MiB以下、総画素数1600万以下 |
| 画像配信 | ログイン確認付きAPIで配信。Next.jsから中継 |
| API中継 | 10秒でタイムアウト。設定で変更可能 |
| 一覧取得 | 既定20件・最大50件、続きはカーソルで取得 |
| ローカル起動 | Web・API・PostgreSQLをComposeで起動 |
| 秘密情報 | ローカル専用の設定・鍵ファイル。公開設定と分ける |

Markdownと数式を共通部品で描画し、生HTML・危険なリンク・TeXの外部操作を許可しない。ライブラリの版は実装開始時に互換性を確認して固定する。

画像の制限を超えた場合は登録を止め、圧縮・縮小して再レビューする。勝手に画像を書き換えない。画像・教材本文は初版でログイン済み利用者向けにする。

認証担当は2026-10-13にAPI側へ変更した。Googleクライアントシークレットと新しいセッション設定はAPI側で管理する。旧案のWeb署名秘密鍵/API公開鍵の配置は不要となる。セッション方式と配置を選定してから移行する。Auth.js用の秘密値を新方式で自動的に使い回すことにはしない。

## 公開範囲は別の判断

アプリをどこへ公開するか、登録データ・根拠記録をGitで公開するかは未決定。この設定案は公開・デプロイの許可を意味しない。最初はローカルでの確認を想定する。

根拠：[react-markdown](https://github.com/remarkjs/react-markdown)、[数式プラグイン](https://github.com/remarkjs/remark-math)、[KaTeX設定](https://katex.org/docs/options.html)。画像上限・タイムアウトは本アプリ向けの提案値。

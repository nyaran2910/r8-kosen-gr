# 本文表示と知識への移動の案

本文表示・知識パネルの方針はユーザー確認済み。実装しない。初版はパソコン向け。

## 共通の表示

問題・解答・解説・知識本文は同じMarkdown表示部品を使う。見出し・リスト・表・コード・リンク・画像と、`$...$`／`$$...$$` のTeX数式に対応する。数式や表が長い場合は、その部分だけ横スクロールにする。

本文中の生HTMLは表示しない。JavaScriptや任意の埋め込みを実行せず、外部サイトのiframeも初版には含めない。対応しない数式記法は登録レビューで検出し、表示を確認してから登録する。

## 知識リンク

演習画面では `/knowledge/<UUID>` のリンクを押すと右側の詳細パネルに知識本文を開く案。別の知識へ辿った履歴を持ち、「戻る」で前の知識へ戻れる。パネルを閉じると元の演習に戻る。

問題のスクロール位置・解答表示状態・入力途中の評価を維持する。知識を開くだけでは新しい演習を作らず、時間計測や評価確定も行わない。知識の理解度変更は明示的な保存操作にする。

知識一覧から開く場合は通常の詳細ページを使い、本文表示部品は共通にする。存在しないリンク先では見つからない旨と戻る操作を表示する。

## 画像

初版は独自作成など利用条件を確認したPNG・JPEG・WebPを対象にする。登録ファイルの画像を配信用ディレクトリへ取り込み、画像本体をDBの本文へ埋め込まない。

画像は代替テキストを持たせ、読み込み失敗時も説明が読めるようにする。原本の図・ローカル絶対パスをそのまま配信しない。初版は外部URLの画像・SVG・画像アップロード画面を対象外とする案。

## 外部リンク

通常のHTTPSリンクは別タブで開き、演習を維持する。内部知識リンクはアプリ内で扱う。参照リンクの閲覧だけで知識を必須評価対象に加えない。

## 初版の範囲

編集・レビューはファイルで行うため、アプリ内のMarkdown編集・プレビュー画面は設けない。具体的な描画ライブラリと画像のサイズ上限・配置は、この表示方針を確認してから選定する。

# 資料利用・公表の方針

更新日：2026-10-09

## 採用する方針

- 原本ファイルから、知識要素・問題傾向の構造化データを直接作り、レビュー後にDBへ登録する。
- 原本の完全な内容は原本ファイルで保持する。問題文・解答・解説を丸ごとDBへ保存する工程は作らない。
- 学習者には独自の説明と、確認済みの自作・生成問題を提供する。
- アプリの出典表示は、引用・利用条件などで必要な範囲に絞る。参照資料をすべて一律に公表する運用にはしない。
- 実際の出典・取得方法・抽出方法は内部記録に残す。
- 研究発表では、結果を支える資料・方法を必要な範囲で正確に示し、根拠を丁寧に確認する。

出典を表示しないことと、事実と違う作成方法を説明することは別。「発覚しないこと」を利用の根拠にはしない。公表範囲を絞っても、解析時の利用条件と生成結果の確認は必要。

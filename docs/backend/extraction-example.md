# 東北大学数学の最小構成の抽出例

知識要素の5分割は確認済み。それ以外の分類は確認用の草案。DB登録は未実施。抽出元は [r8/1.md](../../assets/sources/東北大学過去問/r8/1.md)。以前の小問別分類・共通条件・依存関係の詳細な抽出例を、最小案に置き換える。

## 定義テーブルへ登録する候補

| 定義 | 内容 |
| --- | --- |
| 教科 | 数学 |
| 試験 | 東北大学工学部編入・数学。教科「数学」を参照 |
| ジャンル | 線形代数。教科「数学」を参照 |
| 形式 | 複数の小問から構成される大問（分類候補） |

試験とジャンル・形式を関連づける。形式の説明には、固有値や対角化を計算する小問が並ぶことを記載できるが、この解法専用の形式を必須にはしない。

| 知識要素（分割は確定） | 内容 | コスト |
| --- | --- | --- |
| 固有値 | 特性方程式から固有値を求める | 未決定 |
| 固有ベクトル | 固有値に対応する固有ベクトルを求める | 未決定 |
| ベクトルの正規化 | ノルムを使って単位ベクトルにする | 未決定 |
| 対角化 | 固有ベクトルを用いて行列を対角化する | 未決定 |
| 行列の累乗 | 対角化を利用して行列の累乗を計算する | 未決定 |

この大問には上記5要素を紐づけ、それぞれ「わかった／わからない」で評価する。固有値と固有ベクトル、対角化と行列の累乗は理解度を別々に持つ。コストは各要素に割り当てるが、算出方法・数値は今後決める。同じ知識は他の問題でも共有する。試験側の合計コストまたは要素数の上限、1要素のコスト上限も未決定。

## 登録する抽出データ

上記の教科・ジャンル・形式・5つの知識要素の定義を、原本から直接構造化する。原本の文章や解説を複製せず、知識の説明は自分の表現で作る。試験と対象ジャンル・形式を紐づけ、出典識別情報を残す。

この原本の問題文・解答・解説を `problems` に登録しない。具体的な行列・設問を再現するデータも抽出定義へ持ち込まない。`problems` は後に自作・生成した問題を保存する用途とする。

## 生成時の使い方

「東北大学工学部編入・数学」を指定したら、試験が参照する数学、線形代数、対象形式、レビュー済みの知識候補とコスト制限を取得する。選んだ定義の説明をコンテキストへ入れ、対象に合う大問を生成する。原本は抽出に使い、学習用の問題は別途自作・生成する。

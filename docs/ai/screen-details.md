# 画面詳細3項目のコンテキスト

[ユーザー向け案](../common/screen-details.md) の3項目はユーザー確認済み。実装しない。

## 試験選択とホーム

最近の試験IDだけを同じブラウザーのユーザー別設定として保存する案。ログアウト・アカウント切替で別人の設定を表示しない。保存した試験が存在しなければ試験選択へ戻る。ログイン後の最終試験の復元は同じ端末だけで、端末同期用DB項目は追加しない。復習待ち件数は出題可能な問題の期限到達だけを数える。中断演習は予約状態も含め、別試験のものでも一人一つという既存方針を維持する。

## 一覧と手動変更

知識検索は初版では名称の部分一致で、本文全文検索・pgvector検索は追加しない。教科・ジャンル・未評価または1〜5を組み合わせる。形式は対象試験に属するものだけを対象にする。絞り込み変更時は一覧カーソルをリセットする。APIは認証主体の状態のみ結合し、他人の値を含めない。知識一覧の対象ジャンルは出題範囲の完全な対応とは限らないことを保持する。

手動変更は1〜5のみ。知識状態の行削除で未評価へ戻すAPIは追加しない。下書きの理解度は保存ボタンを押すまでは現在値に反映しない。別タブによる更新は既存expected_updated_atの競合ルールを使う。同値保存でも操作履歴を残す既存仕様。評価途中に知識を手動変更しても、問題の知識二択入力を省略しない。初回二択評価の計算基準3と初回手動設定の直接値は区別する。

## 履歴と設定

日付フィルターは画面のAsia/Tokyoで日付を選び、APIはUTCの下限を含む・上限を含まない範囲へ変換する。確定演習だけを既定一覧とし、終了した未確定演習は学習結果の履歴に混ぜない。本文冒頭抜粋はMarkdown構文・数式を安全な短い文字列へ整形し、HTMLを実行しない。

履歴の復習日時はattempts.scheduled_review_at、現在予定はuser_problem_review_statesを区別して表示する。出題済み問題は別ID訂正、知識の軽微修正は現行本文を参照する既存運用。問題廃止を理由に履歴を消さない。再演習は本人の操作で新IDを作り、未確定演習があれば再開/終了の確認を先に行う。

設定の退会では学習保持・Google側許可は別操作・再登録時別IDを具体的に表示する。見た目を「すべてのデータを削除」としない。退会処理の再送・成功応答が途切れた場合は既存台帳と操作IDで照合する内部契約に合わせる。

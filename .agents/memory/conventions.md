# 協働と実装の進め方

- このセッションではユーザーがアプリコードを自分で書き、エージェントはコード・コマンド・説明を提示し、現状を読み取って確認する方針。新たな明示的依頼がなければアプリのソース・依存関係・設定・マイグレーションを直接変更しない。過去にデモデータと just コマンドの直接追加は個別に依頼された。メモリ更新は AGENTS.md に従って行う。
- 実装は小さく段階的に進め、新しい概念を丁寧に説明する。100行前後を目安とし、慣れた繰り返し作業はまとめてもよい。シンプルな実装を優先し、ライブラリに任せられる部分は任せる。設定やプロジェクトの作成は `uv init` など公式の生成コマンドを優先する。
- 今後提示するコードのコメントは、ユーザーが指定した `insert-comments` スキルに従う。役割、入力・出力、期待する値、型やライブラリを選んだ理由を丁寧に書く。TS/JSの基本文法そのものはコメントで説明不要。ユーザーが質問した言語機能は会話で説明する。スキルの実体: `/Users/nyaran/.dotfiles/home/common/sources/agents/skills/insert-comments/SKILL.md`。
- ユーザーはCLI実装よりアプリ本体の完成を優先。`assets/seeds/demo.sql` の投入コマンドは例外として既に追加済み（`justfile`）。
- Web実装の提案前にも `apps/web/AGENTS.md` の指示に従って、インストール済みNext.jsの関連ガイドを確認する。簡潔なユーザー向け資料と詳細なAI用資料の区分は `docs/README.md` に従う。
